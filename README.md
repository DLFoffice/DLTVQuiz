# ตอบคำถามชิงตุ๊กตา DLTV + แบบสอบถามความพึงพอใจ 🧸🛰️

- **Frontend**: GitHub Pages (โฟลเดอร์ `github-pages/`) — HTML/CSS/JS ล้วน ไม่ต้อง build
- **Backend**: Google Apps Script + Google Sheets (โฟลเดอร์ `gas-backend/` — **ไม่ต้องอัปขึ้น GitHub** เพราะมีเฉลย)

```
github-pages/
  index.html            หน้าเล่นเกม + แบบสอบถาม (ผู้เล่น / ผู้เยี่ยมชมบูธ)
  admin.html            ระบบหลังบ้าน (ไม่มีลิงก์จากหน้าเล่นเกม)
  assets/js/config.js   ⚙️ ใส่ URL ของ Apps Script ที่นี่
  assets/js/api.js      เชื่อมต่อ API + ข้อคำถาม (ไม่มีเฉลย)
  assets/js/app.js      ลำดับหน้าจอ, รับรางวัล, แบบสอบถาม
  assets/js/admin.js    แดชบอร์ด, ตัวกรอง, Export PDF
  assets/js/mascot3d.js น้อง DLTV 3D
gas-backend/Code.gs     API หลังบ้าน (มีเฉลย + ตั้งค่าช่วงเวลา/โควตา)
```

## ลำดับการใช้งานของผู้เข้าร่วม
**ผู้เล่นเกม**: ลงทะเบียน (ชื่อ-สกุล, เบอร์มือถือ, กลุ่ม) → ตอบ 10 ข้อ → ดูคะแนน/เฉลย →
- ได้ **10 คะแนนเต็ม** → ปุ่ม **ขอรับตุ๊กตา DLTV** (ถ้าตุ๊กตาช่วงนั้นหมด หรืออยู่นอกช่วงเวลา → ได้รางวัลปลอบใจแทน)
- ได้ **ต่ำกว่า 10** → ปุ่ม **ขอรับรางวัลปลอบใจ** (หรือเล่นใหม่เพื่อลุ้นตุ๊กตา)
→ ได้ **รหัสรับรางวัล** → ทำ **แบบสอบถามความพึงพอใจ** 7 ข้อ → หน้าขอบคุณแสดงรหัสให้เจ้าหน้าที่ → เจ้าหน้าที่มอบของและติ๊ก "รับของแล้ว" ในชีต `การรับรางวัล`

**ผู้เยี่ยมชมบูธ (ไม่เล่นเกม)**: หน้าแรก → ปุ่ม "ผู้เยี่ยมชมบูธ · ทำแบบสอบถามความพึงพอใจ" → เลือกกลุ่มผู้เข้าร่วม + ให้คะแนน 7 ข้อ

## กติกา
| เรื่อง | ค่าที่ตั้งไว้ (แก้ได้ใน `CONFIG` ของ Code.gs) |
|---|---|
| ตุ๊กตา DLTV | ต้องได้ 10/10 · วันละ 20 ตัว แบ่ง 4 ช่วง ช่วงละ 5 ตัว |
| ช่วงเวลา | 11.00–12.59 · 13.00–14.59 · 15.00–16.59 · 17.00–21.00 น. (นอกช่วง = เล่นได้ แต่ไม่มีตุ๊กตา) |
| รางวัลปลอบใจ | ได้ < 10 คะแนน หรือ 10 คะแนนแต่ตุ๊กตาช่วงนั้นหมด |
| สิทธิ์ | 1 คน (ชื่อ-สกุล หรือ เบอร์โทร) รับรางวัลได้ 1 ครั้ง (ตุ๊กตา *หรือ* รางวัลปลอบใจ) |
| รหัสรางวัล | ตุ๊กตา `DLTV-1105-S2-03` (วันที่-ช่วง-ลำดับ) · ปลอบใจ `GIFT-1105-017` |

## ชีตที่ระบบสร้าง
- `ผู้เล่นเกม` — ทุกครั้งที่เล่น: เวลา, ช่วงเวลา, ชื่อ, เบอร์, กลุ่ม, คะแนน, คำตอบ
- `การรับรางวัล` — ผู้ขอรับรางวัล: ประเภท, รหัส, ☑ **รับของแล้ว** (เจ้าหน้าที่ติ๊ก)
- `แบบสอบถามความพึงพอใจ` — ประเภทผู้ตอบ (ผู้เล่น/ผู้เยี่ยมชม), กลุ่ม, ข้อ 1–7, ค่าเฉลี่ย, ข้อเสนอแนะ (ผู้เล่นเชื่อมกับชื่อ/คะแนน/รางวัลอัตโนมัติ)
- `สรุปรายวัน`, `สรุปตามช่วงเวลา` — สร้างจากเมนู 🧸 DLTV Quiz → 2)

## ติดตั้ง / อัปเดต
1. **แนะนำใช้ Google Sheets ไฟล์ใหม่** (เวอร์ชันนี้ใช้ชีตชื่อใหม่ ชีตเดิม `ผู้เข้าร่วม` จะไม่ถูกใช้แล้ว)
2. ส่วนขยาย → Apps Script → วาง `Code.gs` → ตั้งเขตเวลา `(GMT+07:00) Bangkok`
3. กลับไปที่ชีต รีเฟรช → เมนู **🧸 DLTV Quiz → 1) ตั้งค่าชีต / ดูรหัสผู้ดูแล** → จด ADMIN_KEY
4. ทำให้ใช้งานได้ → เว็บแอป (เรียกใช้ในฐานะ: ฉัน · เข้าถึง: ทุกคน) → คัดลอก URL `/exec`
   (ถ้าอัปเดตโปรเจกต์เดิม: จัดการการทำให้ใช้งานได้ → ✏️ แก้ไข → เวอร์ชันใหม่)
5. ใส่ URL ใน `github-pages/assets/js/config.js` → push ขึ้น GitHub → Settings → Pages
6. หน้าเล่นเกม `https://<user>.github.io/<repo>/` (ทำ QR Code) · หลังบ้าน `.../admin.html`

ถ้ายังไม่ใส่ `API_URL` เว็บทำงานใน **โหมดทดลอง** (แถบสีส้มด้านล่าง ไม่บันทึกข้อมูล)

## ระบบหลังบ้าน (admin.html)
- **ตัวกรอง**: วันนี้ / เมื่อวาน / ทั้งหมด · ช่วงวันที่ (ตั้งแต่–ถึง) · ช่วงเวลา (4 ช่วง + นอกช่วงเวลา)
- ตัวเลขสรุป 8 ช่อง: ผู้เล่น, คะแนนเต็ม, ตุ๊กตาที่แจก/โควตา, รางวัลปลอบใจ, รับของแล้ว, ผู้ตอบแบบสอบถาม, ความพึงพอใจเฉลี่ย, ช่วงเวลาที่คนเล่นมากที่สุด
- กราฟเส้นโค้ง: ผู้เล่นตามช่วงเวลา (แยกรายวัน), ผู้เข้าร่วมรายวัน, การกระจายคะแนน
- ตารางโควตาตุ๊กตา วันที่ × ช่วงเวลา (x/5) · กลุ่มผู้เข้าร่วม · % ตอบถูกรายข้อ · ข้อที่ตอบผิดมากที่สุด
- **แบบสอบถาม**: ตารางความถี่ 5–1, x̄, S.D., ระดับ (4.51–5.00 มากที่สุด … 1.00–1.50 น้อยที่สุด), กราฟค่าเฉลี่ยรายข้อ, กราฟการกระจายระดับ, ข้อเสนอแนะทั้งหมด
- สรุปรายวัน · รายชื่อผู้ขอรับรางวัล (กรองประเภท, ค้นหา, ซ่อนเบอร์)
- **Export PDF** A4 ตามตัวกรองที่เลือก

## รองรับผู้เล่นพร้อมกัน
- ข้อคำถามโหลดจาก GitHub · ตรวจคะแนน/บันทึกการเล่น/แบบสอบถามทำพร้อมกันได้ทุกคน
- เฉพาะขั้น "ขอรับรางวัล" ที่เข้าคิว (อ่านแค่ชีต `การรับรางวัล` ซึ่งมีไม่กี่สิบแถวต่อวัน)
- เน็ตหลุด/ระบบยุ่ง → ลองส่งใหม่อัตโนมัติด้วยรหัสเดิม ไม่บันทึกซ้ำ ไม่ได้รางวัลซ้ำ

## แก้ไขข้อคำถาม / แบบสอบถาม
- ข้อคำถาม: แก้ **2 ที่ให้ตรงกัน** — `QUESTIONS` ใน `Code.gs` (มีเฉลย) และ `QUIZ` ใน `assets/js/api.js`
- ข้อแบบสอบถาม: แก้ `SURVEY_ITEMS` ทั้งใน `Code.gs` และ `assets/js/app.js`
