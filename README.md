# ตอบคำถามชิงตุ๊กตา DLTV + แบบสอบถามความพึงพอใจ 🧸🛰️

- **Frontend**: GitHub Pages (โฟลเดอร์ `github-pages/`) — HTML/CSS/JS ล้วน ไม่ต้อง build
- **Backend**: Google Apps Script + Google Sheets (โฟลเดอร์ `gas-backend/` — **ไม่ต้องอัปขึ้น GitHub** เพราะมีเฉลย)

```
github-pages/
  index.html            หน้าเล่นเกม + แบบสอบถาม (ผู้เล่น / ผู้เยี่ยมชมบูธ)
  admin.html            ระบบหลังบ้าน (ไม่มีลิงก์จากหน้าเล่นเกม)
  assets/js/config.js   ⚙️ ใส่ URL ของ Apps Script ที่นี่
  assets/js/api.js      เชื่อมต่อ API + ข้อคำถาม (ไม่มีเฉลย)
  assets/js/app.js      ลำดับหน้าจอ, รับรางวัล, แบบสอบถาม
  assets/js/admin.js    แดชบอร์ด, ตัวกรอง, Export PDF
  assets/js/mascot3d.js น้อง DLTV 3D
  assets/js/i18n.js     คำแปลภาษาอังกฤษ + ปุ่มสลับภาษา
  assets/js/mascot-themes.js เอฟเฟกต์ 2 ธีม · theme-day.js เลือกธีมของวัน
gas-backend/Code.gs     API หลังบ้าน (มีเฉลย + ตั้งค่าช่วงเวลา/โควตา)
```

## ลำดับการใช้งานของผู้เข้าร่วม
**หน้าแรก** แสดง "วันนี้เหลือตุ๊กตา X / 20 ตัว" (อัปเดตทุก 1 นาที)

**ผู้เล่นเกม**: ลงทะเบียน (ชื่อ-สกุล, กลุ่ม, เบอร์มือถือ — **นักเรียน/นักศึกษาไม่ต้องใส่เบอร์ก็ได้** ระบบตรวจซ้ำด้วยชื่อ-สกุลแทน) → ตอบ 10 ข้อ (**สุ่มลำดับข้อและตำแหน่งตัวเลือก ก–ง ใหม่ทุกครั้งที่เริ่มเล่น** แต่ละเครื่องไม่เหมือนกัน · ตัวเลือก "ถูกทุกข้อ" อยู่ท้ายสุดเสมอ) → **ส่งคำตอบแล้วระบบตัดสินรางวัลจากคะแนนทันที** (ไม่ต้องกดรับ)
- ได้ **10 คะแนนเต็ม** → ตุ๊กตา DLTV (นับจนครบ 20 ตัว/วัน · ถ้าหมดแล้ว → รางวัลปลอบใจ)
- ได้ **ต่ำกว่า 10** → รางวัลปลอบใจ
→ หน้าผลคะแนนแสดง **คะแนนรวม + รหัสรับรางวัล** (ไม่แสดงเฉลยและข้อที่ผิด) → ทำ **แบบสอบถามความพึงพอใจ** 7 ข้อ → หน้าขอบคุณแสดงรหัสให้เจ้าหน้าที่

ระบบบันทึกรางวัลลงชีต `การรับรางวัล` (☑ รับของแล้ว) และคอลัมน์ "รางวัล / รหัสรางวัล" ในชีต `ผู้เล่นเกม` ให้อัตโนมัติ
· **นับตุ๊กตาจากคะแนน**: 1 คน (ชื่อ หรือ เบอร์เดียวกัน) = 1 รางวัล · คนที่ได้ 10 คะแนน = ตุ๊กตา (ตามลำดับเวลา จนครบ 20 ตัว/วัน) · ถ้าเคยได้รางวัลปลอบใจแล้วกลับมาได้ 10 คะแนน ระบบเปลี่ยนเป็นตุ๊กตาให้
· หลังอัปเดต ระบบคำนวณรางวัลทั้งหมดใหม่จากคะแนนในชีต `ผู้เล่นเกม` อัตโนมัติ 1 ครั้ง (เก็บรหัสเดิมและสถานะรับของเดิมไว้) · สั่งซ้ำได้จากเมนู 🧸 DLTV Quiz → คำนวณรางวัลใหม่จากคะแนนในชีตผู้เล่นเกม
· ถ้าผู้เล่นไม่ได้รับของจริง เจ้าหน้าที่กดปุ่มสถานะในหน้า admin เพื่อเปลี่ยนเป็น "รอรับ" ได้

**ผู้เยี่ยมชมบูธ (ไม่เล่นเกม)**: หน้าแรก → ปุ่ม "ผู้เยี่ยมชมบูธ · ทำแบบสอบถามความพึงพอใจ" → เลือกกลุ่มผู้เข้าร่วม + ให้คะแนน 7 ข้อ

| รหัสรางวัล | ตุ๊กตา `DLTV-1105-03` (วันที่-ลำดับ) · ปลอบใจ `GIFT-1105-017` |

## ชีตที่ระบบสร้าง
- `ผู้เล่นเกม` — ทุกครั้งที่เล่น: เวลา, ช่วงเวลา, ชื่อ, เบอร์, กลุ่ม, คะแนน, คำตอบ
- `การรับรางวัล` — ผู้ขอรับรางวัล: ประเภท, รหัส, ☑ **รับของแล้ว** (เจ้าหน้าที่ติ๊ก)
- `แบบสอบถามความพึงพอใจ` — ประเภทผู้ตอบ (ผู้เล่น/ผู้เยี่ยมชม), กลุ่ม, ข้อ 1–7, ค่าเฉลี่ย, ข้อเสนอแนะ (ผู้เล่นเชื่อมกับชื่อ/คะแนน/รางวัลอัตโนมัติ)
- `สรุปรายวัน`, `สรุปตามช่วงเวลา` — สร้างจากเมนู 🧸 DLTV Quiz → 2)

## ติดตั้ง / อัปเดต
1. **แนะนำใช้ Google Sheets ไฟล์ใหม่** (เวอร์ชันนี้ใช้ชีตชื่อใหม่ ชีตเดิม `ผู้เข้าร่วม` จะไม่ถูกใช้แล้ว)
2. ส่วนขยาย → Apps Script → วาง `Code.gs` → ตั้งเขตเวลา `(GMT+07:00) Bangkok`
3. กลับไปที่ชีต รีเฟรช → เมนู **🧸 DLTV Quiz → 1) ตั้งค่าชีต / ดูรหัสผู้ดูแล** → จด ADMIN_KEY
4. ทำให้ใช้งานได้ → เว็บแอป (เรียกใช้ในฐานะ: ฉัน · เข้าถึง: ทุกคน) → คัดลอก URL `/exec`
   (ถ้าอัปเดตโปรเจกต์เดิม: จัดการการทำให้ใช้งานได้ → ✏️ แก้ไข → เวอร์ชันใหม่)
5. ใส่ URL ใน `github-pages/assets/js/config.js` → push ขึ้น GitHub → Settings → Pages
6. หน้าเล่นเกม `https://<user>.github.io/<repo>/` (ทำ QR Code) · หลังบ้าน `.../admin.html`

ถ้ายังไม่ใส่ `API_URL` เว็บทำงานใน **โหมดทดลอง** (แถบสีส้มด้านล่าง ไม่บันทึกข้อมูล)

## ภาษาไทย / English
- ปุ่ม **EN / ไทย** มุมขวาบน (หน้าแรกและหน้าลงทะเบียน) สลับภาษาได้ทันที · ระบบจำภาษาที่เลือกไว้ในเครื่อง
- ลิงก์ภาษาอังกฤษโดยตรง (ทำ QR แยกได้): `https://<เว็บ>/?lang=en`
- แปลครบ: ข้อคำถาม/ตัวเลือก (A B C D), แบบสอบถาม, ข้อความทุกหน้าจอ, ข้อความแจ้งเตือนจากระบบ
- ข้อมูลที่บันทึกเหมือนเดิม (กลุ่ม/รางวัลเป็นภาษาไทย) + คอลัมน์ **ภาษา (TH/EN)** ท้ายชีต `ผู้เล่นเกม` และ `แบบสอบถามความพึงพอใจ`
- คำแปลอยู่ในไฟล์ `assets/js/i18n.js` (แก้ข้อคำถามภาษาอังกฤษที่ `Q_EN`)

## ธีมเอฟเฟกต์ของวัน (สลับอัตโนมัติวันต่อวัน)
- **ดาวเทียม DLTV** (วันที่ 7, 9, 11 … พ.ย.): ดาวเทียมจิ๋วโคจร · คลื่นสัญญาณจากเสาอากาศ · ดาวตก · โทนเหลืองทอง/น้ำเงิน
- **ห้องเรียนฟองสบู่** (วันที่ 8, 10, 12 … พ.ย.): หนังสือ ดินสอ ไม้บรรทัด ตัวอักษร ก ข A B ลอยรอบตัว · ฟองสบู่พาสเทล
- ล็อกธีมเดียวได้ที่ `assets/js/config.js` → `THEME: 'satellite'` หรือ `'learning'` (ค่าเริ่มต้น `'auto'`)
- ดูตัวอย่างอีกธีมได้ทันที: เปิดลิงก์เว็บแล้วต่อท้าย `?theme=learning` หรือ `?theme=satellite`

## ระบบหลังบ้าน (admin.html)
- **ตัวกรอง**: วันนี้ / เมื่อวาน / ทั้งหมด · ช่วงวันที่ (ตั้งแต่–ถึง) · ช่วงเวลา (5 ช่วง 09.00–21.00 + นอกช่วงเวลา)
- ตัวเลขสรุป 8 ช่อง: ผู้เล่น, คะแนนเต็ม, ตุ๊กตาที่แจก/20 ต่อวัน, รางวัลปลอบใจ, รับของแล้ว, ผู้ตอบแบบสอบถาม, ความพึงพอใจเฉลี่ย, ช่วงเวลาที่คนเล่นมากที่สุด
- กราฟเส้นโค้ง: ผู้เล่นตามช่วงเวลา (แยกรายวัน), ผู้เข้าร่วมรายวัน, การกระจายคะแนน
- ตารางการแจกตุ๊กตารายวัน (x/20) แยกตามช่วงเวลาที่แจก · กลุ่มผู้เข้าร่วม · % ตอบถูกรายข้อ · ข้อที่ตอบผิดมากที่สุด
- **แบบสอบถาม**: ตารางความถี่ 5–1, x̄, S.D., ระดับ (4.51–5.00 มากที่สุด … 1.00–1.50 น้อยที่สุด), กราฟค่าเฉลี่ยรายข้อ, กราฟการกระจายระดับ, ข้อเสนอแนะทั้งหมด
- สรุปรายวัน · รายชื่อผู้ขอรับรางวัล (กรองประเภท, ค้นหา, ซ่อนเบอร์) + ปุ่มสถานะต่อแถว (กดเพื่อยกเลิก/ยืนยันใหม่ กรณีพิเศษ)
- **Export PDF** A4 ตามตัวกรองที่เลือก

## รองรับผู้เล่นพร้อมกัน
- ข้อคำถามโหลดจาก GitHub · ตรวจคะแนน/บันทึกการเล่น/แบบสอบถามทำพร้อมกันได้ทุกคน
- เฉพาะขั้น "ขอรับรางวัล" ที่เข้าคิว (อ่านแค่ชีต `การรับรางวัล` ซึ่งมีไม่กี่สิบแถวต่อวัน)
- เน็ตหลุด/ระบบยุ่ง → ลองส่งใหม่อัตโนมัติด้วยรหัสเดิม ไม่บันทึกซ้ำ ไม่ได้รางวัลซ้ำ

## แก้ไขข้อคำถาม / แบบสอบถาม
- ข้อคำถาม: แก้ **2 ที่ให้ตรงกัน** — `QUESTIONS` ใน `Code.gs` (มีเฉลย) และ `QUIZ` ใน `assets/js/api.js`
- ข้อแบบสอบถาม: แก้ `SURVEY_ITEMS` ทั้งใน `Code.gs` และ `assets/js/app.js`
