# ตอบคำถามชิงตุ๊กตา DLTV 🧸🛰️

เว็บกิจกรรมตอบคำถาม 10 ข้อเกี่ยวกับมูลนิธิการศึกษาทางไกลผ่านดาวเทียม ในพระบรมราชูปถัมภ์
ตอบถูก **8 ข้อขึ้นไป** รับตุ๊กตา DLTV — มีน้องนักบินอวกาศ DLTV แบบ 3D ที่ขยับตอบสนองตลอดการเล่น

- **Frontend**: GitHub Pages (HTML/CSS/JS ล้วน ไม่ต้อง build) + three.js จาก CDN
- **Backend**: Google Apps Script + Google Sheets (เก็บข้อมูลผู้เล่นรายวัน/รายช่วงเวลา)

```
index.html            หน้าเล่นเกม
dashboard.html        หน้าสรุปผลสำหรับเจ้าหน้าที่
assets/js/config.js   ⚙️ ใส่ URL ของ Apps Script ที่นี่
assets/js/app.js      ลำดับหน้าจอ, transition, confetti, พื้นหลังดาว
assets/js/mascot3d.js น้อง DLTV 3D (three.js)
assets/js/api.js      เชื่อมต่อ API (+ โหมดทดลอง)
assets/img/           โลโก้มูลนิธิ, โลโก้ DLTV, ภาพน้อง DLTV (สำรองกรณีเครื่องไม่รองรับ 3D)
```

## 1) ตั้งค่าหลังบ้าน (Google Apps Script)
1. สร้าง Google Sheets ใหม่ → **ส่วนขยาย → Apps Script**
2. วางโค้ดจากไฟล์ `Code.gs` (แยกไว้ในโฟลเดอร์ `gas-backend` — **ไม่ต้องอัปขึ้น GitHub** เพราะมีเฉลย) ทับไฟล์ Code.gs เดิม แล้วบันทึก
3. **การตั้งค่าโปรเจกต์ ⚙** → เขตเวลา `(GMT+07:00) Bangkok`
4. กลับไปที่ชีต รีเฟรช → เมนู **🧸 DLTV Quiz → 1) ตั้งค่าชีต / ดูรหัสผู้ดูแล** (อนุญาตสิทธิ์ครั้งแรก) → จด **ADMIN_KEY**
5. (ถ้าต้องการ) **ตั้งจำนวนตุ๊กตาต่อวัน**
6. Apps Script → **ทำให้ใช้งานได้ → การทำให้ใช้งานได้รายการใหม่ → เว็บแอป**
   - เรียกใช้ในฐานะ: **ฉัน** · ผู้มีสิทธิ์เข้าถึง: **ทุกคน**
7. คัดลอก URL ที่ลงท้ายด้วย `/exec`

> แก้โค้ด GAS ภายหลัง: **จัดการการทำให้ใช้งานได้ → ✏️ แก้ไข → เวอร์ชัน: ใหม่** (URL เดิม)

## 2) ขึ้น GitHub Pages
1. เปิด `assets/js/config.js` ใส่ URL จากข้อ 1.7 ที่ `API_URL`
2. push ไฟล์ในโฟลเดอร์นี้ขึ้น repo (เฉลยไม่ได้อยู่ในหน้าเว็บ จึงเปิด repo เป็น public ได้)
3. GitHub → **Settings → Pages → Deploy from a branch → main / (root)**
4. ได้ลิงก์ `https://<user>.github.io/<repo>/` → นำไปทำ QR Code ที่บูธ
5. หน้าสรุปผล: `https://<user>.github.io/<repo>/dashboard.html` → กรอก ADMIN_KEY

ถ้ายังไม่ใส่ `API_URL` เว็บจะทำงานใน **โหมดทดลอง** (มีแถบสีส้มด้านล่าง ไม่บันทึกข้อมูล) ใช้ดูหน้าตาได้

## กติกา
- 10 ข้อ ได้ ≥ 8 คะแนน = ได้ตุ๊กตา + **รหัสรับรางวัล** เช่น `DLTV-1104-001` ให้แสดงต่อเจ้าหน้าที่
- 1 เบอร์โทร รับรางวัลได้ 1 ครั้ง (เล่นซ้ำได้) · จำกัดจำนวนตุ๊กตาต่อวันได้
- ไม่ผ่าน: บอกเลขข้อที่ผิด (ไม่เฉลย)
- ตรวจคะแนนที่ GAS เท่านั้น หน้าเว็บไม่มีเฉลย

## ข้อมูล & การวิเคราะห์
ชีต **ผู้เข้าร่วม**: Timestamp · วันที่ · เวลา · ชั่วโมง · ช่วงเวลา · ชื่อ · เบอร์ · กลุ่ม · คะแนน · ผ่าน · ได้รางวัล · รหัส · หมายเหตุ · เวลาที่ใช้ · คำตอบ · ☑ รับตุ๊กตาแล้ว

**dashboard.html** (อัปเดตทุก 1 นาที): จำนวนครั้ง/คนไม่ซ้ำ/ผ่าน/แจก, กราฟรายวัน, กราฟรายชั่วโมง + ช่วงพีค, กลุ่มผู้เข้าร่วม, การกระจายคะแนน, heatmap วันที่ × ช่วงเวลา
เมนูในชีต **2) อัปเดตชีตสรุป** สร้างชีต `สรุปรายวัน` และ `สรุปรายชั่วโมง` (ตั้ง Trigger รายชั่วโมงได้)

## น้อง DLTV 3D
แตะที่น้อง = กระโดด/หมุนตัว · ปัดซ้าย-ขวา = หมุนดูรอบตัว · หัวหันตามนิ้ว/เมาส์
ท่าทาง: โบกมือ, พยักหน้าเมื่อเลือกคำตอบ, ส่ายหัวเมื่อยังไม่เลือก, ฉลองเมื่อได้รางวัล, เศร้าแล้วให้กำลังใจเมื่อไม่ผ่าน
เครื่องที่ไม่รองรับ WebGL จะแสดงภาพ 2D แทนอัตโนมัติ
